MA PETITE FERME — V59.07

Objectif de cette version : remettre les interactions de gameplay au premier plan avant la refonte du Stock.

- Prairie : fonctionnement actuel conservé.
- Bois enchanté : clic sur une parcelle -> action contextuelle Planter / Attendre / Couper selon son état.
- Mine ancienne : clic sur une parcelle -> Extraire ou Cultiver, puis Attendre / Récolter selon son état.
- Mode Édition : disponible sur toutes les cartes, y compris la Zone de production. Les placements restent sauvegardés séparément par zone.
- Bâtiments : limite actuelle portée à 5 niveaux pour les bâtiments déjà améliorables.
- Améliorations : paiement en ressources du domaine, plus en pièces.
- Niveau 5 : structure buildingStars conservée à 0 pour permettre de futurs paliers Étoiles sans casser les sauvegardes.
- Zone de production : clic sur un bâtiment installé affiche son niveau, son avantage et, si configuré, le coût en ressources du prochain niveau.
- Moulin : rendement des rations augmente avec son niveau ; la recette Farine est disponible à partir du niveau 2.
- Scierie / Atelier minier : leurs avantages existants continuent d'évoluer avec le niveau.
- Stock : ancien affichage volontairement conservé dans cette version. Refonte prévue après validation gameplay.

Aucun reset de sauvegarde imposé : migration compatible avec les zones et placements V59 existants.
